# 模型思考深度 + Base URL 模型探测 + 三协议自定义配置

## 现状结论（已核实）

- LLM 调用链：`Settings` → `LLMFactory.get_all_llms()` → `LLM.chat()` → `BaseProvider.call()`，目前只透传 `max_tokens/top_p`，**无任何思考深度参数**。
- 配置保存：前端 `ApiDialog.vue` → `POST /save-api-config` 只更新内存 settings（camelCase：apiKey/modelId/baseUrl/apiType/contextWindow），前端 localStorage 持久化、提交任务前会重传，重启不丢。
- 已有 `POST /validate-api-key` 可作为新接口的风格模板。
- **发现的既有缺口**：前端 `SaveApiConfigRequest`（apiKeyApi.ts）缺 `contextWindow` 字段，表单里有但从未上送——顺手修复。

## 设计

### 1. 思考深度：每个 Agent 两个新配置项

- `XXX_REASONING_EFFORT: Optional[str]`——档位字符串，原样透传给 API（覆盖你 ZCode 配置里全部供应商的档位：GLM 的 low/high/max、DeepSeek 的 off/high/max、muse 的 minimal/xhigh）
- `XXX_THINKING_BUDGET: Optional[int]`——Anthropic 协议专用的 thinking 预算（budget_tokens）

**三协议映射**（在各 Provider 内实现）：

| 协议 | effort 处理 | budget 处理 |
|---|---|---|
| openai-chat | 非 off → `reasoning_effort=<原样>`；off/空 → 不传 | 忽略 |
| openai-responses | 非 off → `reasoning={"effort": ...}`；off/空 → 不传 | 忽略 |
| anthropic | off → 不传 thinking；low/medium/high/max → 按映射表换算 budget | `thinking={"type":"enabled","budget_tokens":N}` |

- anthropic effort→budget 映射表（模块级常量，可调）：`low=8192, medium=16384, high=32768, max=65536`；且 clamp 到 `max_tokens-1024` 之内（Anthropic 要求 budget < max_tokens）
- openai 系容错：部分兼容端点不认识 `reasoning_effort` 会 400，Provider 内捕获 `BadRequestError` 后去掉该参数重试一次

### 2. 模型探测：新增 `POST /list-models`

- 请求 `{api_key, base_url, api_type}`，按协议用 SDK 自带接口：
  - openai-chat / openai-responses → `AsyncOpenAI(...).models.list()`（GET {base_url}/models）
  - anthropic → `AsyncAnthropic(...).models.list()`（GET {base_url}/v1/models）
- 返回 `{success, models: [id...], message}`，错误分类风格复用 validate-api-key

### 3. 前端配置弹窗（ApiDialog.vue）增强

每个 Agent 表单新增：
- **思考深度** Select：默认(空)/off/minimal/low/medium/high/max/xhigh 八档
- **思考预算** Input（number，说明文案：仅 Anthropic 协议生效）
- **Model ID 探测按钮**：调 `/list-models`，成功后 Model ID 输入框挂原生 `<datalist>` 建议列表（可输可选，零新依赖），toast 反馈结果

自定义 base_url 本就支持（自由输入），本次保证三种协议下探测/验证/思考深度全适配。

## 已知取舍

- effort 档位为固定 8 项 Select，不做自由输入（档位体系各家不同，透传未知值容易 4xx；有需求后续可加"自定义"）
- 配置持久化维持现状（前端 localStorage + 提交前重传），不落盘 .env.dev
- `simple_chat`（记忆压缩）不带思考深度，保持轻量
